# Prompt 6 – Request for Missing Patient Information

## Version 1

Write a message asking a patient for missing information.

## Version 2

Write a polite message requesting missing patient information. Include the patient’s first name, information required, reason, deadline, and instructions for providing the information.

## Final Version

You are assisting the administration team in a physiotherapy clinic. Create a polite and professional message requesting missing administrative information or documentation from a patient using only the information provided.

Include:

- Patient first name
- Information or document required
- Reason it is required, if provided
- Instructions for how the patient can provide it
- Deadline, if provided
- Clinic contact details, if provided

Keep the message respectful, simple, and easy to understand.

Only request the information specifically listed.

Do not request unnecessary medical or sensitive information.

Do not invent deadlines or reasons.

Do not assume why the information is missing.

If the request is unclear or incomplete, clearly state that staff confirmation is required.

## Example Input

Patient first name: Rachel
Information required: Medicare card details
Reason: Required to complete billing records
Instructions: Please email the details to reception
Deadline: 21 August 2026
Clinic contact: reception@centralphysio.com.au

## Improvement Notes

Version 1 did not identify what information was required or why.

Version 2 added the main request details.

The final version added privacy controls, limits on unnecessary information requests, clear instructions for missing details, and a respectful patient communication style.
